# Nyota
*Interplanetary Exoplanet Research Archive on the Blockchain*

## 🌌 Overview

Nyota (Swahili for "star") is a decentralized exoplanet discovery management system built on blockchain technology. It provides astronomers with a secure, immutable, and transparent platform to register, verify, and share their exoplanet discoveries while maintaining proper attribution and research ownership.

## ✨ Features

- **Secure Registration**: Register new exoplanet discoveries with comprehensive metadata
- **Ownership Management**: Clear attribution and transfer capabilities for research rights
- **Data Verification**: Immutable verification system to establish scientific credibility
- **Privacy Controls**: Configurable privacy settings for ongoing research
- **Comprehensive Metadata**: Store detailed information about stellar categories, orbital parameters, radiation levels, and more
- **Astronomer Portfolios**: Track all discoveries by specific astronomers

## 🔭 Technical Details

Nyota is implemented as a Clarity smart contract with a robust data structure designed to handle the complexities of exoplanetary research data:

- **Clarity Smart Contract**: Secure, predictable execution with formal verification capabilities
- **Comprehensive Data Validation**: Built-in parameter validation for scientific accuracy
- **Efficient Data Structures**: Optimized for blockchain storage while maintaining data integrity
- **Permission Controls**: Proper authorization checks for data modifications

## 📋 Data Structure

Exoplanet records include:

- **Basic Details**: Name, stellar category, composition type
- **Environmental Parameters**: Orbital range, radiation levels, atmosphere density
- **Metadata**: Spectral signatures, discovery timestamps
- **Settings**: Privacy controls, verification status
